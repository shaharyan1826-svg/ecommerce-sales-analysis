# E-Commerce Sales Analysis & Product Category Prediction

## 📌 Project Overview

This project analyzes an e-commerce sales dataset using Python and explores sales patterns through data analysis and visualization.

The project also uses Machine Learning to predict the product category of an order based on transaction-related features.

## 🎯 Objectives

- Analyze e-commerce sales data
- Check and clean the dataset
- Analyze sales by product category
- Analyze regional and payment-method patterns
- Study relationships between quantity, price, discount, and revenue
- Build a Machine Learning classification model
- Evaluate the model using accuracy, confusion matrix, and classification report

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Jupyter Notebook

## 🤖 Machine Learning

The project uses **Logistic Regression** to predict:

**Target:** `product_category`

Features used include:

- Quantity
- Unit Price
- Discount
- Delivery Days
- Customer Rating
- Revenue

Payment Method was also explored as an additional feature.

## 📊 Model Performance

The Logistic Regression model achieved approximately:

**Accuracy: 46.35%**

The result shows that the selected transaction features have limited ability to predict product categories. This provides an opportunity for future improvement through better feature engineering and additional relevant data.
